README operativo

Operación, seguridad y recuperación

Guía para administrar el bot sin abrir terminales visibles.

1. Flujo seguro por cliente

  1. Abre un chat individual desde la cuenta de WhatsApp vinculada.
  2. Envía exactamente START BOT CANADA o START BOT USA.
  3. El bot crea o retoma solamente ese expediente y conserva el avance.
  4. Para detener cualquier flujo de ese chat, envía STOP BOT. Detiene Canadá y USA a la vez.
Los mensajes del cliente nunca pueden activar el bot. Texto parecido, palabras adicionales, grupos y difusiones se ignoran.

2. Comandos permitidos

START BOT CANADA
Inicia o reanuda Visa Canadá.
START BOT USA
Inicia o reanuda Visa USA.
START BOT ETA
Reservado; informa que eTA aún no está habilitado y no crea expediente.
STOP BOT
Detiene todos los flujos abiertos del chat.

Mayúsculas/minúsculas no importan; el texto completo sí debe coincidir.

3. Inicio automático de Windows

La tarea programada ejecuta el supervisor oculto, recompila, inicia Node sin ventana, revisa la salud cada 15 segundos y reinicia el proceso tras tres fallas.

npm run windows:install
npm run windows:status

Ejecuta la instalación desde PowerShell como administrador para arrancar incluso antes del login. Sin elevación también se instala de forma segura, pero arranca al iniciar sesión.

4. Detener e iniciar el proceso

Stop-ScheduledTask -TaskName "ACME Client Intake Bot"
Start-ScheduledTask -TaskName "ACME Client Intake Bot"

Para reiniciar, ejecuta primero Stop y después Start. Estos comandos controlan toda la aplicación. STOP BOT solo detiene el flujo del cliente y mantiene el dashboard disponible.

5. Troubleshooting

  • WhatsApp pide QR: pulsa el estado de WhatsApp arriba y escanéalo desde Dispositivos vinculados.
  • El cliente no recibe nada: confirma que el comando fue enviado por ti, en el chat individual, y que arriba diga “Conectado”.
  • El panel no abre: ejecuta npm run windows:status y revisa .data/logs/supervisor.log.
  • Google desconectado: pulsa Google Drive y autoriza de nuevo.
  • Proceso con error: usa Restart-ScheduledTask; el avance está persistido en SQLite.

6. Validación antes de producción

  • WHATSAPP_AUTOSTART=true
  • WHATSAPP_BROWSER_VISIBLE=false
  • La tarea programada aparece activa en npm run windows:status.
  • WhatsApp y Google Drive figuran conectados.
  • Prueba START/STOP con un chat controlado antes de usar clientes reales.
